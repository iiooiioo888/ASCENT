# API v1

| 項 | 值 |
| --- | --- |
| 前綴 | `/api/v1` |
| 規則來源 | [GDD v2.0 §12](../gdd/production-system-v2.md#12-api) · [GDD 0005](../gdd/0005-schema-and-api.md) |
| 模組歸屬 | [architecture/overview.md](../architecture/overview.md) |
| 權威 | 伺服器。GET 可結算實體時先懶結算。前端預覽不得寫回庫存 |

本檔列 HTTP 契約；實作在 `apps/api`（NestJS 模組見下表）。MVP 不啟用 Socket.IO。

## 路由歸屬

| 路徑前綴 | NestJS 模組 | 純計算 |
| --- | --- | --- |
| `GET /api/v1/time` | `inventory` | `simulation.GameClock` |
| `GET /api/v1/item-*` | `catalog` | 無結算 |
| `GET /api/v1/production-*`、`/loops`、`POST /validate` | `rules` | `Validator` 等 |
| `GET/POST /api/v1/inventory`、`/buildings`、`/state` | `inventory` | `Settlement` |
| Socket.IO | `realtime` | 無（MVP 關） |

禁止在 `simulation` 開 Controller 或 Gateway。

## 時間

| 方法 | 路徑 | 行為 | MVP |
| --- | --- | --- | --- |
| GET | `/api/v1/time` | 回傳 `startRealTime`、`startGameTime`、`serverRealTime`、`displayGameTime`、`timeScale=60`。僅顯示，不結算、不推進 `lastSettledAt`。 | 是 |

```json
{
  "startRealTime": "2026-10-06T00:00:00.000Z",
  "startGameTime": 0,
  "serverRealTime": "2026-10-06T00:10:00.000Z",
  "displayGameTime": 36000,
  "timeScale": 60
}
```

`displayGameTime = startGameTime + (serverRealTime − startRealTime) / 1000 × 60`。

## 庫存與建築

寫入前必須先懶結算。開工：先結算再扣輸入。停止：先結算，**不退還**已扣輸入（**已拍板 D6**）；亦不回滾已入帳產出。UI 停止前應列損失（Draft PR #5 U4）。收取：先結算再發已入帳產出。

種子世界預放建築（**已拍板 D2**）：田、磨坊、爐、**水井**各 1 座（`seedPlacedBuildingDefIds`）。水井僅能開 `method_draw_water_default`，田另可 `method_save_seed_default`。汲水可無輸入；汲水／留種數值仍為佔位（見 shared `PLACEHOLDER_*`）。

| 方法 | 路徑 | 行為 | MVP |
| --- | --- | --- | --- |
| GET | `/api/v1/inventory` | 懶結算後的庫存 | 是 |
| GET | `/api/v1/state` | 懶結算後的庫存 + 建築 + 進行中生產 | 是 |
| GET | `/api/v1/buildings` | 列表；每筆回傳前結算 | 是 |
| GET | `/api/v1/buildings/:id` | 單筆；先結算 | 是 |
| POST | `/api/v1/buildings` | 放置建築 | 是 |
| POST | `/api/v1/buildings/:id/start` | 選定 `method_id` 開工 | 是 |
| POST | `/api/v1/buildings/:id/stop` | 停止 | 是 |
| POST | `/api/v1/buildings/:id/collect` | 收取 | 是 |

## 原稿路徑對照

GDD 原稿「GET time / items / types / rules / methods / loops / state；POST method / stop / buildings」落地如下（不另開第二套路徑）：

| 原稿 | 本檔 |
| --- | --- |
| GET time | GET /api/v1/time |
| GET items / types | GET /api/v1/items、/item-types |
| GET rules / methods / loops | GET /api/v1/production-rules、/production-methods、/loops |
| GET state | GET /api/v1/state |
| POST method | POST /api/v1/buildings/:id/start（選定方式開工） |
| POST stop | POST /api/v1/buildings/:id/stop |
| POST buildings | POST /api/v1/buildings |

開工 JSON 範例：

```json
{
  "methodId": "method_iron_ingot_basic",
  "inputs": {
    "item_iron_ore": 1,
    "item_coal": 1
  }
}
```

寫入前必須先懶結算。切換方式（目標首發）：先結算 → 扣成本 → 再套新方式。
