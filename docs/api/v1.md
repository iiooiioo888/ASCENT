| 路徑前綴 | NestJS 模組 | 純計算 |
| --- | --- | --- |

| `GET /api/v1/production-*`、`/loops`、`POST /validate` | `rules` | `Validator` 等 |
| `GET/POST /api/v1/inventory`、`/buildings`、`/state` | `inventory` | `Settlement` |

| Socket.IO | `realtime` | 無（MVP 關） |

## 時間

| 方法 | 路徑 | 行為 | MVP |
| --- | --- | --- | --- |
| GET | `/api/v1/time` | 回傳 `startRealTime`、`startGameTime`、`serverRealTime`、`displayGameTime`、`timeScale=60`。僅顯示，不結算、不推進 `lastSettledAt`。 | 是 |

```json
{
  "startRealTime": "2026-10-06T00:00:00.000Z",
  "startGameTime": 0,
  "serverRealTime": "2026-10-06T00:10:00.000Z",
  "displayGameTime": 36000,
  "timeScale": 60
}
```

`displayGameTime = startGameTime + (serverRealTime − startRealTime) / 1000 × 60`。

## 庫存與建築

寫入前必須先懶結算。開工：先結算再扣輸入。停止：先結算，**不退還**已扣輸入（**已拍板 D6**）；亦不回滾已入帳產出。UI 停止前應列損失（Draft PR #5 U4）。收取：先結算再發已入帳產出。

種子世界預放建築（**已拍板 D2**）：田、磨坊、爐、**水井**、**莊外商行**各 1 座（`seedPlacedBuildingDefIds`）。水井僅能開 `method_draw_water_default`，田另可 `method_save_seed_default`；商行 `bdef_trading_post` 無生產規則（市集見下節）。汲水可無輸入；汲水／留種數值仍為佔位（見 shared `PLACEHOLDER_*`）。

種子世界預放建築（**TODO(product) 待確認**）：田、磨坊、爐、水井（`seedPlacedBuildingDefIds`）；水井僅能開 `method_draw_water_default`，田另可 `method_save_seed_default`。汲水可無輸入；數值見 shared catalog 佔位常數。

| 方法 | 路徑 | 行為 | MVP |
| --- | --- | --- | --- |
| GET | `/api/v1/inventory` | 懶結算後的庫存 | 是 |
| GET | `/api/v1/state` | 懶結算後的庫存 + 建築 + 進行中生產 | 是 |
| GET | `/api/v1/buildings` | 列表；每筆回傳前結算 | 是 |
| GET | `/api/v1/buildings/:id` | 單筆；先結算 | 是 |
| POST | `/api/v1/buildings` | 放置建築 | 是 |
| POST | `/api/v1/buildings/:id/start` | 選定 `methodId` 開工 | 是 |
| POST | `/api/v1/buildings/:id/stop` | 停止 | 是 |
| POST | `/api/v1/buildings/:id/collect` | 收取 | 是 |

### 寫入 HTTP 狀態碼（工程 MVP）

NestJS 預設：`POST` 成功為 `201 Created`，除非另有 `@HttpCode`。下列訊息字串與 `apps/api` 實作一致。

| 路徑 | 成功 | `400 Bad Request` | `404 Not Found` | `409 Conflict` |
| --- | --- | --- | --- | --- |
| `POST /api/v1/validate` | `201 Created`（body 含 `ok`、`errors`、`generatedPreview`；驗證失敗時 `ok: false` 仍為 `201`） | — | — | — |
| `POST /api/v1/buildings` | `201 Created` | 「未知建築」 | — | — |
| `POST …/start` | `201 Created` | 「未知生產方式」；「此建築不能使用該方式」；「建築忙碌或待收取」；「資源不足：{itemId}」 | 「建築不存在」 | 「建築狀態已變更，請重新整理」（`updateMany` 未命中預期 `status`）；懶結算樂觀鎖重試耗盡時「建築結算衝突，請重試」 |
| `POST …/stop` | `201 Created`（含 `idle` 上 no-op：仍回 `201`，行為等同冪等成功；**待確認：可能改為 `409`**） | — | 「建築不存在」 | 同上兩則 `409`（`idle` no-op 現不回 `409`） |
| `POST …/collect` | **`200 OK`**（`@HttpCode(200)`） | — | 「建築不存在」 | 「建築狀態已變更，請重新整理」（非 `ready` 或已被收取）；懶結算「建築結算衝突，請重試」 |

`start`／`stop`／`collect` 在單一 Node 進程內另以 `SettlementMutex` 序列化；多實例部署仍依上表 `409` 與樂觀 `lastSettledAt` 結算。

## 市集（NPC 商行）

> TODO(product)：價目平衡、可交易清單、貨幣是否改 `Player.gold`、品牌名仍未定。  
> **已拍板**：貨幣為庫存 `item_gold`；開局金幣 **10**（`STARTING_GOLD`）；價目權威 `game_config.market_prices`（缺省回退 shared 常數）。  
> 世界實體：`bdef_trading_post`（莊外商行）開局預放 1 座；交易仍走本節 HTTP，唔綁建築 `start`／`collect`。

寫入前必須先懶結算。單一 DB 交易原子扣／加；與建築寫入共用進程鎖，避免雙花。買賣唔受 `POST .../stop` 退款規則影響（**已拍板：停止唔退料**）。

| 方法 | 路徑 | 行為 | MVP |
| --- | --- | --- | --- |
| GET | `/api/v1/market` | 回傳 `gold`、`prices`（`sell`／`buy`）、可交易品 `holdings` | 是 |
| POST | `/api/v1/market/sell` | body `{ itemId, quantity }`；扣物加金幣 | 是 |
| POST | `/api/v1/market/buy` | body `{ itemId, quantity }`；扣金幣加物 | 是 |

**佔位價（金幣）**

| 方向 | 物品 id | 單價 |
| --- | --- | --- |
| 賣 | `item_bread` | 8 |
| 賣 | `item_feed` | 3 |
| 賣 | `item_flour` | 4 |
| 賣 | `item_dough` | 5 |
| 賣 | `item_wheat` | 2 |
| 賣 | `item_straw` | 1 |
| 買 | `item_seed_wheat` | 3 |
| 買 | `item_water` | 1 |

禁止賣／買 `item_gold`；未列物品拒絕。

| 條件 | HTTP | message 例 |
| --- | --- | --- |
| 數量無效 | 400 | `數量無效` |
| 庫存不足 | 400 | `資源不足：item_bread` |
| 金幣不足 | 400 | `金幣不足` |
| 不可交易 | 400 | `不可交易：item_*` |
| 競態（庫存被併發改動） | 409 | 同結算衝突文案 |

`GET /api/v1/state` 的 `inventory` 含金幣列（`item_gold`），無另開 `wallet` 欄。

賣出範例：

```json
{ "itemId": "item_bread", "quantity": 1 }
```

成功回傳含 `side`、`itemId`、`quantity`、`unitPrice`、`goldDelta`。

## 原稿路徑對照

GDD 原稿「GET time / items / types / rules / methods / loops / state；POST method / stop / buildings」落地如下（不另開第二套路徑）：

| 原稿 | 本檔 |
| --- | --- |
| GET time | GET /api/v1/time |
| GET items / types | GET /api/v1/items、/item-types |
| GET rules / methods / loops | GET /api/v1/production-rules、/production-methods、/loops |
| GET state | GET /api/v1/state |
| POST method | POST /api/v1/buildings/:id/start（選定方式開工） |
| POST stop | POST /api/v1/buildings/:id/stop |
| POST buildings | POST /api/v1/buildings |

開工範例（農業 MVP 種子；建築 `pb_player_local_bdef_field` 為田地）：

```http
POST /api/v1/buildings/pb_player_local_bdef_field/start
Content-Type: application/json

{
  "methodId": "method_grow_wheat_default"
}
```

寫入前必須先懶結算。切換方式（目標首發）：先結算 → 扣成本 → 再套新方式。
