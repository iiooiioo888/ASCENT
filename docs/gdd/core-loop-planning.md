# 核心玩法北星｜空間效率 × 時間規劃 = 利潤

| 項 | 值 |
| --- | --- |
| 狀態 | **LOCKED**（產品體驗北星；設計文檔法源） |
| 日期 | 2026-10-08 |
| 溯源 | 《创业王》核心機制提煉；用戶確認「流程模組 ≠ 核心」 |
| 與既有法源 | 不刪減 [system-definition.md](../system-definition.md)「生產鏈深度」；本檔補**怎麼玩**（規劃），生產鏈深度仍是**內容深度** |

---

## 一句話

**核心不是「經營」，是「規劃」。**  
利潤是規劃質素的結果，不是玩家可直接點選或單獨操作的對象。

---

## 公式（LOCKED）

```
核心玩法 = 空間效率 × 時間規劃 = 利潤
```

| 因子 | 含義 | 玩家操作對象 |
| --- | --- | --- |
| **空間效率** | 每一塊地磚、每一段動線都是成本；地段＝運輸成本 × 客群匹配 | 佈局、選址、垂直整合 |
| **時間規劃** | 工人每一步、每一秒閒置都在燒錢 | 工位、工資、開工節奏、減少空轉 |

兩因子相乘：任一側規劃差，利潤被壓縮；兩側同時優化，利潤才會放大。利潤是**輸出指標**，不是第二套核心機制。

---

## 空間效率（摘要）

- **地與槽**：土地、建築佔槽、擴田 cap 是粗粒度的空間預算；多佔一槽或多走一段路，都轉成運輸與佔用成本。
- **選址與整合**：買地、內部供應鏈、農→磨→爐→零售等垂直整合，本質是在二維／拓撲上縮短「料從哪來、貨到哪去」的距離與不匹配。
- **現階段落地**：尚無廠內二維格子與可視化動線；透過庫存分組、田休地、LAND 槽位、運費代理等**已有 state** 讓空間約束「可被讀懂」，完整空間模擬後叠。

---

## 時間規劃（摘要）

- **人力與工位**：開工扣薪、工位佔用、idle／busy／done 是時間是否在燒錢的直接信號。
- **節奏與空轉**：隊列、開停工、AFK／智能調度、跟市價定價，都是在減少等待與錯配造成的隱性時間成本。
- **現階段落地**：運費／工資（OD-R1）已作時間／距離代理；步數級工人路徑與手動拖派尚未開啟，以建築卡 ETA、工位摘要等 FE 可見性承載「時間規劃」語意。

---

## 流程模組 ≠ 核心機制

買地、建廠、生產、銷售是**遊戲流程**，玩家會經過，但不是北星公式本身。用公式回看各流程：

| 流程 | 核心讀法 |
| --- | --- |
| 買地 | 運輸成本與客群匹配的空間解 |
| 建廠 | 二維平面上的空間效率優化（後叠） |
| 生產線 | 用物理空間換生產效率（後叠） |
| 內部供應鏈 | 垂直整合，省外部運輸時間 |
| AI／對手 | 擠壓空間餘地與時間窗口 |

規格與 PR 評審時：功能是否讓**空間或時間規劃**更可見、更可操作，比是否多一個「經營按鈕」更重要。

---

## 與現況模組對齊

現階段**沒有**廠內二維格子／可視化工人拖曳。北星先透過**已有 state 的可見性與成本語意**落地；完整空間模擬後叠。本表描述設計對齊，**不要求**本檔 PR 改動 runtime。

| 現有模組 | 對齊因子 | 近線落地（不改 BE 語意） |
| --- | --- | --- |
| **建築卡（FE-RICH-1）** | 時間規劃 | 顯示 idle／busy／done、進度／ETA、工位佔用、auto、預估工資／運費——讓「閒置與等待」可見 |
| **庫存＋田卡（FE-RICH-2）** | 空間效率（粗） | 庫存分組與田休地／天氣——空間／節奏約束可見，唔另開 vault |
| **商行／零售（FE-RICH-3）** | 空間×時間→利潤 | 貨架 ask／followMarket、客單 bid、今日收入、銅錠結算——規劃結果可見 |
| **HUD／三錠（FE-RICH-4＋#60）** | 利潤結果 | 銅銀金錠餘額＋工位摘要——結算與人力壓力一眼可見 |
| **運費／工位／工資（OD-R1）** | 時間規劃 | 開工扣薪、運費＝時間／距離代理成本（尚未可視化步數） |
| **LAND／擴田、槽 cap** | 空間效率 | 地塊與佔槽是粗粒度空間預算 |
| **AFK／智能調度** | 時間規劃（自動） | 減少空轉；跟市價＝把定價當規劃結果持續校準 |
| **內部鏈（農→磨→爐→零售；牧場／食品廠）** | 垂直整合 | 省外部買料時延＝時間成本代理 |

### 後叠（明確未開）

不在 FE-RICH／三錠 HUD／VPS 現行切片內開發：

1. 廠內機器／棧板／上下貨區二維佈局  
2. 可視化工人路徑與步數成本  
3. 地段分區（工業／商圈）客群匹配  
4. 手動暫停、拖工人到機台
