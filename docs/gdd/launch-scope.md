| 項 | 值 |

| 規則法源 | [GDD v2.0 §13](production-system-v2.md#13-首發範圍)；[0007](0007-scope-expansion.md) |

本檔只展開**目標首發**、核心循環、統計與改版節奏。禁止寫第二套 T/P、第二套公式或第二套入帳 cap。衝突時：規則聽 [production-system-v2.md](production-system-v2.md) 與 [0007](0007-scope-expansion.md)；產品範圍聽系統定義；工程驗收聽 mvp.md。

時間系統與主 GDD／ADR 一致：懶結算、`timeScale=60`（**1 真實秒 = 60 遊戲秒 = 1 遊戲分鐘**），不是每遊戲秒 tick 建築。入帳離線上限 **8 現實小時**。

## 1. 首發內容包

| 包 | 目標首發 | 備註 |
| --- | --- | --- |
| 農業 | 開 | 核心循環 |
| 礦業 | 開 | 核心循環 |
| 基礎化工 | 開 | 核心循環 |
| 通用 | 開 | 核心循環 |
| 能源 | 開（循環約束） | 供給／消耗，不是獨立科技樹大包 |
| 物流 | 可選 | 不強制 |
| T2 同位素 | **關** | `is_active=false`；已啟用規則不得引用 |

物品目標 50–100；稀有度 4–5 級；品質連續 0–100%。建築：可升級、專精不可逆、耐久只影響效率、佔地可擴張、相鄰加成（schema 預留；工程 MVP 不要求）。

工程 MVP：**僅農業**、5–10 物品、3–5 建築、5–10 方式。見 [mvp.md](../mvp.md)。不得把下表統計縮成農業切片。

---

## 2. 核心循環

`LoopGenerator` 必須能標出五條：

| 循環 | 含義 |
| --- | --- |
| 農業 | T 採集／種植 → P 加工 |
| 礦業 | T 開採 → 精製／冶煉 |
| 化工 | 基礎化工中間體與產物 |
| 通用 | 跨系統零件與通用件 |
| 能源 | 供給與消耗約束，讓其他循環能跑 |

物品互為輸入輸出可以成**產業迴圈**。規則繼承、層級依賴、公式參照仍禁止循環（DAG）。

---

## 3. 目標首發統計（設計目標，非引擎硬頂）

下列數字是**內容包規模目標**，不是引擎上限。方式由規則生成，引擎對 `production_methods` 種類**無硬頂**。物品總數須落在系統定義的 50–100。

| 項 | 數量 | 狀態 |
| --- | --- | --- |
| T1 | 25 | 開 |
| T2 | 8 | **關閉**（同位素） |
| P1 | 17 | 開 |
| P2 | 13 | 開 |
| P3 | 6 | 開 |
| 物品合計 | 69（含關閉的 8） | 落在 50–100 |
| 建築定義 | 32 | 目標首發目錄 |
| 規則 | 8 | `production_rules` |
| 生產方式 | ~50 | 由規則生成，約數 |

層級建議工時帶（資料可配，不是引擎寫死）見 [GDD v2.0 §3.5](production-system-v2.md#35-層級工時帶時間組件式可配)。

## 4. 改版節奏

| 階段 | 做 | 不做 |
| --- | --- | --- |
| 工程 MVP | 農業切片 + 懶結算 + 存檔 | 登入、市場、排行、Redis、WS、加速、Phaser |
| v1.0 目標首發 | 本檔產業包；驗證清單全過；上表統計落地 | T2 同位素開啟；Phaser 進核心；客戶端寫回庫存 |
| v1.x | 觀測、驗證報表、只改資料平衡 | 改引擎原則；跳級；改 1:60 |
| v2.0 內容 | 開啟 T2 同位素（改旗標 + 完整驗證） | 改成多親欄位合併；每遊戲秒 tick 建築 |

可擴展性 L1–L4 見 [GDD §16](production-system-v2.md#16-可擴展性)。改框架或改時間比例必須另開 ADR。路線圖：[roadmap.md](../roadmap.md)。

時間系統始終是**懶結算**（`timeScale=60`），不是每遊戲秒 tick 建築。入帳離線上限始終是 **8 現實小時**。
