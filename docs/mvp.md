## 一句話

做出「農業切片能生產、離線最多補 8 現實小時、能自動存檔」的可玩閉環。沒有登入、沒有市場、沒有排行榜、沒有 WebSocket。

---

## 範圍（必做）

| 項 | 規格 | 驗收 |
| --- | --- | --- |
| 系統 | 恰好 **1** 個：農業 | 目錄裡沒有已啟用的礦業／化工／通用／能源大包 |
| 物品 | **5–10** 個，皆屬農業切片 | 數量落在閉區間；每筆有類型、`layer`（T 或 P）、`derived_tier` |
| 建築 | **3–5** 座（或 3–5 種可建造建築） | 能放置／開工／收取；不必做專精、佔地擴張、相鄰加成 |
| 生產方式 | **5–10** 種 | **由規則生成**，每筆有 `rule_id`；禁止手寫孤兒方式 |
| 生產 | 選定方式開工，時間到可收取，庫存增減 | 走同一結算入口；伺服器權威 |
| 離線結算 | 離開後再開仍補產，上限 **8 現實小時** | `maxOfflineRealSec=28800`；超過不補更早歷史 |
| 存檔 | **自動存檔** | 權威狀態在 PostgreSQL；重新進頁能讀回庫存與建築游標 |
| 時間 | `timeScale=60`；懶結算；冪等 | 公式見下；無加速 |

## 非目標（明確不做）

| 項 | 說明 |
| --- | --- |
| 登入／JWT／第三方帳號 | MVP 無身分系統；單機／單存檔即可（實作時可固定一個本地 `owner_id`） |
| 玩家市場 | 系統定義列為非 MVP |
| 排行榜 | 同上 |
| 資源互助 | 同上 |
| Redis / BullMQ | 目標棧保留；MVP 不啟用。結算不強依 Redis |
| WebSocket / Socket.IO | 目標棧保留；MVP 只用 HTTP 輪詢或進頁 GET |
| 雲端鎖定 | 不把 Railway／Render 寫進必做 |
| 視覺打磨、地圖、Phaser | 數據畫面即可 |
| 升級／專精／耐久／佔地／相鄰 | 目標建築能力；MVP 不要求 |
| 稀有度 4–5 級、品質 0–100% | 目標首發；MVP 物品可先不帶這些欄 |
| 加速 | 永遠不做（產品決策，不限 MVP） |
| AI 訂單 | 核心循環之後的資源出口，見 [gdd/ai-orders.md](gdd/ai-orders.md)。不進 MVP：不生成、不接受、不過期 |

AI 訂單的完整設計在 [gdd/ai-orders.md](gdd/ai-orders.md)。它是核心循環之後的資源出口，不進本檔「範圍（必做）」。`is_active` 保持關閉。工程 MVP 仍是：農業、5–10 物品、離線結算、存檔；無登入、無市場、無排行榜。

## 時間與結算契約（MVP 必須遵守）

顯示用遊戲時間（不入庫）：

```
gameTime = startGameTime + (now - startRealTime) / 1000 × 60
```

| 鍵 | 值 |
| --- | --- |
| `timeScale` | `60` |
| `maxOfflineRealSec` | `28800`（**8 現實小時**） |
| `maxOfflineGameSec` | `1728000`（= 8 × 3600 × 60 = 480 遊戲小時 = **20 遊戲日**） |

離線上限採系統定義：**8 現實小時**。正確換算：8 現實小時 = 28,800 **現實秒** × 60 = **1,728,000 遊戲秒** = 480 遊戲小時 = **20 遊戲日**。超過此窗口不結算。

**更正原稿誤算：** 原稿「8 小時現實時間 = 8×60×60=28800 遊戲秒 = 遊戲內 8 小時」與 1:60 矛盾，**不入帳**。GDD 原稿 `maxOfflineGameSec=86400` 只保留為 1 遊戲日（24 現實分鐘）的日長，**已被系統定義覆寫**。見 [系統定義 §5.2](system-definition.md#52-更正原稿誤算)。

MVP 結算時機（無 Redis／BullMQ）：

1. `GET` 庫存或建築（進頁即結算）。
2. `POST` 開工／停止／收取。
3. 可選：前端定時輪詢同一 GET。
4. 可選：**NestJS cron**（`@nestjs/schedule`），呼叫與 `inventory` **同一**結算入口。不是遊戲秒迴圈，也不取代懶結算。

仍須：伺服器唯一權威、純函數可重播、同一區間不重複入帳、先裁切現實差再 × 60。細則：[GDD 0002](gdd/0002-time-and-settlement.md)。之後若有登入，改為登入時補結算；MVP 無登入，以進頁代替。

## 農業切片（占位，不是數值定案）

**ID 與 DAG 已定**：[gdd/mvp-agriculture-catalog.md](gdd/mvp-agriculture-catalog.md)（8 物品、4 建築、5 根規則、5–10 方式）。顯示名可改；層、依賴、驗證對照不可另寫一套。產率與工時倍數仍留給開工後的數值表。結構必須合法（不跳級、DAG、方式由規則生成、繼承深度 ≤ 10）。

驗證器清單（[GDD v2.0 §15](gdd/production-system-v2.md#15-驗證清單)、[GDD 0005](gdd/0005-schema-and-api.md)、[切片對照](gdd/mvp-agriculture-catalog.md)）凡與已啟用資料有關的項目，農業切片也必須能過。`V-OFFLINE` 使用本檔的 8 現實小時常數，不用舊稿 86400。

隊列：MVP 可把每座建築隊列長度鎖成很小的常數（例如 1），滿足「隊列有限制」。切換成本、半自動循環：MVP 可只做「開工後依時間產出、進頁收取」；半自動與切換成本可留到目標首發。

## 自動存檔

| 項 | 規格 |
| --- | --- |
| 權威 | PostgreSQL 中的世界時鐘、建築游標、庫存 |
| 時機 | 每次成功結算／開工／收取後即為已存；不另做「手動存檔」為必做 |
| 載入 | 重新進頁：讀庫 → 懶結算 → 回傳 |
| 身分 | 無登入；單一本地存檔即可 |

## MVP 技術約束（不改目標棧）

| 項 | MVP（分期） | 目標（仍寫在 ADR 0001，不刪） |
| --- | --- | --- |
| 語言 | TypeScript | 同左 |
| 前端 | React + Vite | 同左 |
| 後端 | NestJS 單體 + HTTP | 同左；模組可先只接 `catalog` / `rules` / `simulation` / `inventory` |
| 主庫 | PostgreSQL 單實例 + Prisma | 同左 |
| Redis + BullMQ | **不啟用** | 保留；何時引入見系統定義 §10.2 |
| Socket.IO | **不啟用** | 保留；何時引入見系統定義 §10.2 |
| 背景補算 | 可選 NestJS cron，無 Redis | BullMQ `jobs` |
| 本機 | Docker Compose（至少 Node + Postgres） | Compose 含 Redis 服務檔可先寫著但不啟動 |
| 雲端 | 不鎖定；若要試跑可用單一服務 | 不鎖定供應商 |
| 認證 | 無 | 之後簡單 JWT，無第三方 |

原則：現成 > 自寫、單體 > 微服務、一庫 > 拆分、手動 > 自動化、簡單 > 複雜。

## API：哪些屬 MVP，哪些後繼

路徑 `/api/v1`。GET 可結算實體時先懶結算。明細：[gdd/0005-schema-and-api.md](gdd/0005-schema-and-api.md)、[api/v1.md](api/v1.md)。

| 方法 | 路徑 | MVP | 後繼 |
| --- | --- | --- | --- |
| GET | `/time` | 是 | — |
| GET | `/item-types`、`/items` | 是 | — |
| GET | `/production-rules`、`/production-methods` | 是 | — |
| GET | `/loops` | 可延後 | 目標首發 |
| GET | `/state`（或 inventory + buildings） | 是 | — |
| POST | `/buildings` | 是 | 放置 |
| POST | `/buildings/:id/start` | 是 | 開工 |
| POST | `/buildings/:id/stop` | 是 | 停止 |
| POST | `/buildings/:id/collect` | 是 | 收取 |
| POST | `/validate` | 可 | 內容擴充必做 |
| WS | Socket.IO | **否** | 互動／推送期 |
| — | 登入／市場／排行榜 | **否** | 玩家互動期 |

## 驗收清單

- [ ] 農業 5–10 物品、3–5 建築、5–10 由規則生成的方式，驗證器可過。
- [ ] 開工後經過對應遊戲秒，收取使庫存增加；客戶端預覽不得寫回。
- [ ] 離線（或把 `lastSettledAt` 撥早）再進頁，補算不超過 8 現實小時（`maxOfflineRealSec=28800`，遊戲秒上限 `1728000`）。
- [ ] 同一結算區間重放不雙計。
- [ ] 重開應用／重進頁後庫存與建築狀態仍在。
- [ ] 無登入頁、無市場、無排行榜。
- [ ] 無 Redis、無 WebSocket 仍能完成上述閉環。
- [ ] 無加速。
