## 現況（已可玩）

主介面**每個產業一張選項卡**：農業、礦業、林木、化工、工業、能源。一次只開一個。

| 已有 | 落點 |
| --- | --- |
| 農業主線 | 種 → 磨 → 麵 → 烤；水井汲水、田留種 |
| 農業支線 | 牧場（飼料＋水 → 蛋、奶）；磨坊拌飼料 |
| 產業擴充 | 礦坑、採石場、林地、冶煉爐、窯、化工廠、工坊、機械廠、鍋爐；食品廠（麵粉＋蛋＋奶 → 蛋糕） |
| 商行 | NPC 固定價；結算貨幣是庫存 **`item_copper_ingot`**，開局 **50,000** 銅錠。價目已簽核 |
| 零售 | 商行零售只賣麵包；貨架可跟市 |
| 莊股 | 糧莊、磨坊股、爐灶股（手續費與價格帶已在程式） |
| 自動化 | 建築可指定 `autoMethodId`；僱工上限 8 |
| 土地 | 佔槽上限 **12**（倉不佔槽、產業擴充建築不佔此槽）；田上限 2 |
| 時間 | 懶結算、`timeScale=60`、離線 **8 現實小時**；運轉中確定性耐久磨損 |
| 登入 | JWT access（15 分）＋旋轉 refresh。`POST /api/v1/auth/register`、`/login`、`/refresh`、`/logout`，`GET /auth/me`。第一個帳號接上既有 `player_local` 世界。寫入有速率限制。契約見 [api/v1.md](api/v1.md) |
| 進度 | 產業選項卡受里程碑鎖（農業永遠開；礦業要收取 4 麵包起） |
| 仍沒有 | 玩家對玩家市場、排行榜、完整 F4 AI 訂單、Redis、WebSocket、T2 同位素、勝利條件 |

開局仍只預放農業建築。產業建築要玩家自己放，每種最多 1 座。

## 未來開發任務

對應路線圖期 6（登入、市場、排行、AI 訂單）與期 7（Redis、WebSocket）。產品已決定先開 **F1**。F2 起仍要前一項的完成樣子達到才開，不要同時做 Redis 與 WebSocket。

NPC 商行維持固定價，不改成玩家掛單。結算貨幣維持庫存 `item_copper_ingot`。懶結算、`timeScale=60`、離線 8 現實小時、伺服器權威都不改。

| 序 | 狀態 | 任務 | 前置 | 完成樣子 |
| --- | --- | --- | --- | --- |
| F1 | 完成 | **登入** | 無 | 簡單 JWT，無第三方、無 OAuth。Access 短 TTL＋旋轉 refresh。每個請求帶玩家身分，不再寫死單一本地 `owner_id`。登入進頁走現有懶結算入口補算。既有單機存檔能對上該玩家的第一個世界，或明確另開新檔。寫入端點有速率限制 |
| F2 | 之後 | **玩家對玩家市場** | F1 | 玩家掛單買賣，成交扣庫與入帳走 `inventory` 同一入口，貨幣是 `item_copper_ingot`。與 `/api/v1/market` 的 NPC 固定價分開，不取代商行。客戶端不能寫回權威庫存 |
| F3 | 之後 | **排行榜** | F1 | 多維排行（至少產量與資產兩維），名次由伺服器從 PostgreSQL 算出。玩家只看自己的名次與榜單，不能回寫分數 |
| F4 | 之後 | **AI 訂單** | F1 | 只實作 [gdd/ai-orders.md](gdd/ai-orders.md)。`orders` 模組；扣庫與發獎走 `inventory`。生成與過期走懶結算，路徑禁止 `Math.random()`。`is_active=false` 時不生成。玩家可見文字不出現「假」或「AI」。獎勵種類 `gold` 入帳到 `item_copper_ingot`，不建 `Player.gold` |
| F5 | 之後 | **Redis** | F3 或結算變慢 | Redis + BullMQ。Session、排行熱狀態、未發請求時的粗 tick 放這裡。BullMQ 只呼叫與 `inventory` 相同的結算入口。權威庫存與 `lastSettledAt` 仍在 PostgreSQL。`packages/shared` 不依賴 Redis 客戶端。引入條件聽 [系統定義 §10.2](system-definition.md) |
| F6 | 之後 | **WebSocket** | F2 或停留頁完工反饋不夠 | NestJS Gateway + Socket.IO。只推已入帳的 `settlement`、`production_complete`，以及市場已成交狀態。斷線不影響已入帳資料。重連仍用 HTTP GET 拉權威 |

各項不得：

| 任務 | 不得 |
| --- | --- |
| F1 | 改成 OAuth；為登入改 1:60 或離線上限 |
| F2 | 把 NPC 商行價目改成玩家撮合；水平多實例沒有列鎖就開放同時成交 |
| F3 | 用 Redis 當名次主庫；客戶端上報分數 |
| F4 | 另寫第二套訂單規則；結算路徑用隨機數；v1 寫入 `accepted` |
| F5 | Redis 當主庫；BullMQ 另寫扣庫公式；為了「目標棧有 Redis」在沒有上表條件時先接上 |
| F6 | Gateway 計算庫存或推未入帳結果；用 WebSocket 取代懶結算 |
